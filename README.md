| Proje | Ne yaptım? | Algoritma / model |

| [**pcb-defect-detection**](https://github.com/sametsel/pcb-defect-detection) | PCB elektronik kartlarda 6 sınıf arıza tespiti; Colab’da eğitim + çıkarım | **YOLOv8n**, CNN tabanlı object detection, mAP değerlendirme |
| [**video-ai-musicgen**](https://github.com/sametsel/video-ai-musicgen) | Videodan sahne analizi → müzik üretimi → videoya montaj | **BLIP** (image captioning) + **MusicGen** (Meta AudioCraft) |

**PCB projesi — teknik özet**

- Eğitim: 50 epoch, 640×640, batch 16, Tesla T4
- Sınıflar: missing_hole, mouse_bite, open_circuit, short, spur, spurious_copper

**MusicGen projesi — teknik özet**
- Video karesinden sahne tanımı (vision-language)
- Metin prompt ile sinematik müzik üretimi
- MoviePy + FFmpeg ile ses-video birleştirme
